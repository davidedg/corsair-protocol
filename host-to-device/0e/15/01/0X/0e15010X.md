# `0e 15 01 0X` - Query Xth mode ID

This returns a 16-byte GUID, plus a 4-byte "modified" flag for the Xth mode. With the exception of the K95, most keyboards and mice have only one mode.

Example response:

```
0e [Read command]
15 [Mode ID]
01 [??? - required to be 1]
01 [Query 1st mode ID]
<16 byte little endian GUID, omitted for brevity>
<4 byte little endian modified flag, omitted for brevity>
```

## K95 RGB Platinum

With firmware 3.29 iCUE 5 was not seen sending this command to the K95 RGB Platinum: the identities of its on-board profiles are in its on-board file system, read with [`0e 17 04`](../../../17/04/0e1704.md) and written with [`07 15 SS 00`](../../../../07/15/SS/00/0715SS00.md) ([devices/k95p.md](../../../../../devices/k95p.md)).
