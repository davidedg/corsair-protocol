# `0e 16 01 0X` - Query Xth mode name

This returns a null-terminated 16 character UTF-16LE string.

Example response:

```
0e [Read command]
16 [Mode name]
01 [??? - required to be 1]
01 [Query 1st mode name]
48
00 [U+0048 'H']
77 
00 [U+0077 'w']
4d 
00 [U+004d 'M']
<etc for another 26 bytes>
```

## K95 RGB Platinum

With firmware 3.29 iCUE 5 was not seen sending this command to the K95 RGB Platinum: the names of its on-board profiles are in its on-board file system, in the [PROFILE.I](../../../../../formats/cape/profile-i.md) of each slot ([devices/k95p.md](../../../../../devices/k95p.md)).
