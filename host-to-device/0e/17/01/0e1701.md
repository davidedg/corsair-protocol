# `0e 17 01` - Query the transfer buffer size (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../devices/k95p.md)). The reply gives the size of the buffer through which file data travels: bytes 14 and 15, `2c 01` = 300 bytes, five chunks of 60 bytes ([`ff NN LL 00`](../../../ff/NN/LL/00/ffNNLL00.md), [`7f NN SS 00`](../../../7f/NN/SS/00/7fNNSS00.md)). The other bytes of the reply are left over from the previous reply.

Example (only bytes 14 and 15 are new; the rest is the previous reply, a slot table):

```
> 0e 17 01 00
< 0e 17 01 00 1a a3 48 4e ce ce 4c 3e 87 b4 2c 01 2f cd b6 3a dd 02 00 01 f7 0c d7 9d 00 fe 4e cb ...
                                            ^^^^^ 0x012c = 300
```
