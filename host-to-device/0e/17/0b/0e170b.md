# `0e 17 0b` - Query the free space (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../devices/k95p.md)). The reply gives, as a u32 at bytes 4 to 7, the free bytes of the flash memory of the on-board profiles: always a multiple of 4096, since the files take whole sectors of 4 KiB. The used and the free sectors add up to 2038.

iCUE sends it once before writing a slot, before clearing it, so the files the slot has then are counted as used. For example, a reply of `0x7ce000` free bytes is 1998 free sectors, with 40 sectors of files on the keyboard.

A file takes ceil(size / 4096) sectors, at least one ([space](../../../../formats/cape/README.md#space)).
