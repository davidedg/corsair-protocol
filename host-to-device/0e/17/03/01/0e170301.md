# `0e 17 03 01` - Query the size of the open file (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../../devices/k95p.md)). The reply gives, as a u32 at bytes 4 to 7, the size of the file opened with [`07 17 07 00`](../../../../07/17/07/00/07170700.md).

```
> 0e 17 03 01
< 0e 17 03 01 0c 01 00 00 ...        268 bytes (a PROFILE.I)
```
