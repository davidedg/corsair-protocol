# `0e 17 03 00` - Query the size of the selected slot (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../../devices/k95p.md)). The reply gives, as a u32 at bytes 4 to 7, the bytes used by the slot selected with [`07 17 0c 0X`](../../../../07/17/0c/0X/07170c0X.md): the sum of the sizes of its files, 0 for an empty slot.

For example, bytes 4 to 7 `82 05 00 00` are 1410 bytes.

iCUE reads it only before writing a slot. It is not the size of a file: that is [`0e 17 03 01`](../01/0e170301.md).
