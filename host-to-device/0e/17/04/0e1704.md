# `0e 17 04` - Query the slot table (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../devices/k95p.md)). The reply lists the three on-board profile slots, 20 bytes each from byte 4:

```
offset  size  field
0       16    GUID of the profile, in the byte order of its text form (1aa3484e-cece-4c3e-87b4-75df2fcdb63a = 1a a3 48 4e ce ce 4c 3e 87 b4 75 df 2f cd b6 3a)
16      3     revision cookie (u24)
19      1     01: the slot holds a profile
```

An empty slot is 20 zero bytes. The entries are set with [`07 15 SS 00`](../../../07/15/SS/00/0715SS00.md); the same GUID and cookie are in the [PROFILE.I](../../../../formats/cape/profile-i.md) of the slot.

```
> 0e 17 04 00
< 0e 17 04 00 | 1a a3 48 4e ce ce 4c 3e 87 b4 75 df 2f cd b6 3a | dd 02 00 | 01 |   slot 0: GUID, cookie 733
                f7 0c d7 9d 00 fe 4e cb 8d 6f 5d bc b2 cc e5 2a | 77 06 00 | 01 |   slot 1: GUID, cookie 1655
                00 ×20                                                             slot 2: empty
```

The cookie is chosen by the host: iCUE raises it at every save of a profile, from 0 for a new one, and wraps it from `0xfffffe` to 0. iCUE recognises its own profiles on the keyboard by GUID and cookie.
