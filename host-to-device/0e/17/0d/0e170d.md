# `0e 17 0d` - Query the status of the last file operation (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../devices/k95p.md)). Byte 4 of the reply is the status of the last command of field `0x17` or [`07 15`](../../../07/15/SS/00/0715SS00.md):

| Byte 4 | Meaning |
|---|---|
| `00` | done |
| `04` | file not found (after an open) |
| `0d` | invalid or unknown |

iCUE's error messages for this byte also name a full file system, a full file table, a file already open, an invalid name or size and a flash write failure; none of them has been seen.

The keyboard answers when it is done: after clearing a slot it can take up to 2.2 s (longer for a slot with more files), after setting a slot entry about 0.4 s, after an open about 0.1 s, after a burst about 40 ms. A host waits for the reply to each status query, with a timeout of a few seconds, and asks again only for an answer that is neither done nor an error.
