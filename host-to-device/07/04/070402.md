### `07 04 02` - Special function software control

On mice, this makes the physical DPI and sniper buttons generate events, but the mouse will do nothing about them by itself. On keyboards, this generates driver events for the M-keys. This is the default in Corsair mode.

## K95 RGB Platinum

In software mode the K95 RGB Platinum does not run the macros of its active on-board profile: a G key with a macro sends only its Corsair event. With a key input table in mode `c0` ([`07 40 NN 00`](../40/NN/00/0740NN00.md)) every key arrives both as a HID event and as a Corsair event; the profile button arrives as a Corsair event and does not switch slot. Whether the firmware applies the remaps of the profile in this mode was not tested. (In hardware mode the keys arrive as HID events only; only the keys without a HID usage, a G key without an action for instance, send Corsair events.)
