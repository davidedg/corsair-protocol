# `07 17 0a` - Fill the read buffer (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../devices/k95p.md)). Fills the 300-byte read buffer with the next bytes of the file opened with [`07 17 07`](../07/00/07170700.md); the host then reads them in chunks with [`ff NN LL 00`](../../../ff/NN/LL/00/ffNNLL00.md). **It is needed before every burst of reads**: without it the `ff` replies return stale data. Check the status ([`0e 17 0d`](../../../0e/17/0d/0e170d.md)) after it.
