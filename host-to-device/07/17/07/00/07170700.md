# `07 17 07 00 <name>` - Open a file for reading (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../../devices/k95p.md)). Opens, in the slot selected with [`07 17 0c 0X`](../../0c/0X/07170c0X.md), the file `<name>` for reading; the name is ASCII from byte 4, zero terminated. Check the status ([`0e 17 0d`](../../../../0e/17/0d/0e170d.md)) after it: `04` means that the file does not exist (close with [`07 17 08`](../../08/071708.md) and go on). The size of the open file is [`0e 17 03 01`](../../../../0e/17/03/01/0e170301.md).

```
> 07 17 07 00 50 52 4f 46 49 4c 45 2e 49 00     open "PROFILE.I" for reading
```
