# `07 17 08` - Close the open file (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../devices/k95p.md)). Closes the file opened with [`07 17 05`](../05/00/07170500.md) or [`07 17 07`](../07/00/07170700.md), also after an open that found no file. It does no harm with no file open, so a host can send it before its first open, to close a file that an interrupted session left open.
