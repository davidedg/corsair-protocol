# `07 17 09` - Commit a burst of written data (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../devices/k95p.md)). Writes to the open file the burst of [`7f NN SS 00`](../../../7f/NN/SS/00/7fNNSS00.md) chunks just sent: up to five chunks, 300 bytes. One per burst; check the status ([`0e 17 0d`](../../../0e/17/0d/0e170d.md)) after it.
