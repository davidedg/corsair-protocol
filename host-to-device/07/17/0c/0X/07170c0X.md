# `07 17 0c 0X` - Select an on-board profile slot (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../../devices/k95p.md)). Selects slot `X` (0 to 2) for the file commands that follow. **It does not change the active profile**, nor the lighting the keyboard shows: only the profile button does ([active slot](../../../../../devices/k95p.md#slots)).

iCUE numbers the slots from 1 in its interface: its "HW Profile 1" is slot 0.
