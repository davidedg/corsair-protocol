# `07 17 05 00 <name>` - Open a file for writing (K95 RGB Platinum)

Part of the on-board profile file system of the K95 RGB Platinum ([devices/k95p.md](../../../../../devices/k95p.md)). Opens, in the slot selected with [`07 17 0c 0X`](../../0c/0X/07170c0X.md), the file `<name>` for writing, creating it or emptying it. The name is ASCII from byte 4, at most 12 bytes with the terminating zero ([files](../../../../../formats/cape/README.md)). Check the status ([`0e 17 0d`](../../../../0e/17/0d/0e170d.md)) after it.

The data follows in bursts of [`7f NN SS 00`](../../../../7f/NN/SS/00/7fNNSS00.md) chunks, each burst committed with [`07 17 09`](../../09/071709.md); [`07 17 08`](../../08/071708.md) closes the file. A file is always written whole: there is no command to delete a single file.

Example: `PROFILE.DAT` with one entry (20 bytes, one chunk):

```
> 07 17 05 00 50 52 4f 46 49 4c 45 2e 44 41 54 00
> 0e 17 0d 00                              < 0e 17 0d 00 00
> 7f 01 14 00 50 01 01 00 02 4d 30 30 30 1e 00 00 00 01 01 00 00 00 00 00
> 07 17 09
> 0e 17 0d 00                              < 0e 17 0d 00 00
> 07 17 08
```
