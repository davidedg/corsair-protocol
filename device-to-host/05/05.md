# `05` - Mouse report of the K95 RGB Platinum

The K95 RGB Platinum has a mouse among the HID reports of its interface 0: report `05`, 10 bytes, on the interrupt IN endpoint `0x81`. In hardware mode the firmware sends it for a key remapped to a mouse button in the active on-board profile ([PROFILE.MAP](../../formats/cape/profile-map.md), destinations `c8` to `cc`).

```
05 [Report ID]
02 00 00 00 [Buttons as a bit field, 32 bits: bit 0 is button 1 (left), bit 1 button 2 (right), ... bit 4 button 5]
00 00 [X, signed 16 bits]
00 00 [Y, signed 16 bits]
00 [Wheel, signed 8 bits]
```

Pressing a key remapped to the right button sends `05 02 00 ...`, releasing it `05 00 00 ...`. A host that holds the keyboard has to take this report as mouse input, or the remap does nothing.

The firmware also sends all-zero `05` reports (no button pressed) when the profile button is pressed in hardware mode, together with all-zero reports `01` and `02`, before the Corsair event of the button.
